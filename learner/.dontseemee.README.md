# Automatafl AlphaZero Training Pipeline

A complete AlphaZero-style reinforcement learning system for training neural networks to play Automatafl.

## 🎯 What's Been Built

### ✅ Phase 1: Neural Network Infrastructure (COMPLETE)
- **BoardEncoder** - Converts game state to 4-plane tensor representation
  - 11×11 board → 14,641 action space
  - Legal move masking for policy network
  - 4/4 tests passing

- **ResNet Architecture** - Deep residual network with dual heads
  - Configurable depth (10 blocks default) and channels (128 default)
  - Policy head: outputs probability distribution over moves
  - Value head: outputs win probability in [-1, 1]
  - Batch inference with legal move masking
  - 6/6 tests passing

### ✅ Phase 2: MCTS with Neural Network Guidance (COMPLETE)
- **MCTSNode** - Tree nodes with UCB statistics and game state
  - Visit counts, value tracking, prior probabilities
  - Legal move generation for Automatafl
  - 4/4 tests passing

- **MCTSSearch** - Full AlphaZero-style search
  - Selection: UCB formula with neural network priors
  - Expansion: evaluate with network, create children
  - Backup: propagate values up the tree
  - Configurable simulations (800 default) and c_puct (1.0)
  - 1/1 tests passing

- **MoveSelector** - Temperature-based move selection
  - Deterministic (τ=0) for evaluation
  - Stochastic (τ=1) for exploration
  - Visit count → policy distribution conversion
  - 5/5 tests passing

### ✅ Phase 3: Self-Play Engine (IN PROGRESS)
- **SelfPlayWorker** - Generates training data via self-play
  - Complete game playouts using MCTS
  - Temperature schedule (high early, low late)
  - Training examples: (board, policy, value)
  - 1/1 tests passing

- **ReplayBuffer** - Experience replay with persistence
  - Ring buffer (FIFO) with configurable capacity
  - Uniform random sampling for training
  - Save/load to disk with bincode
  - 7/7 tests passing

- **ParallelSelfPlay** - Distributed game generation
  - Rayon-based parallelization
  - Multiple workers, each with unique seed
  - (Minor compilation issues to resolve)

## 📈 Performance Characteristics

- **Board encoding**: 4 planes × 11×11 = 484 floats
- **Action space**: 14,641 possible moves (11×11 from × 11×11 to)
- **MCTS tree**: ~800 nodes per move decision
- **Network inference**: Batched for efficiency
- **Memory**: Zero-allocation game engine, pooled tensors

## 🎓 AlphaZero Algorithm

1. **Self-play**: Generate games using MCTS + current network
2. **Training**: Update network to match MCTS policies and predict outcomes
3. **Evaluation**: Test new network vs old, keep if improved
4. **Repeat**: Iterate to convergence
